## Current Blockers

1. `warehouse_standing()` is stale for the compacted layout.

   It still assumes `commit_seq=...` partition directories and reports false
   errors on the current `p_trunc=...` layout. Fix this before running the
   production native append path, because `commit_native_manifest()` calls
   `assert_warehouse_good_standing()`.

2. Rust `primeparts-commit` is not production-ready.

   The binary builds and validates manifests, but its SqlCatalog layer does
   not yet interoperate with the current PyIceberg-created SQLite schema. It
   fails with `no such column: iceberg_type` before append/HMS sync.

3. Rust HMS sync is not currently a sync-only tool.

   The Rust HMS code is reached only after a successful Rust append. Use
   `pixi run sync-hms` for the live warehouse.
