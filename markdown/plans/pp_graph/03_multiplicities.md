# 03 — routing multiplicities against the sieve null

The first measurement designed to find mess rather than confirm structure:
collapse-class multiplicities are counts the free algebra says nothing about.

- [ ] Turn the reachability DP into a counting DP: number of n=1 routings
      between each feeder endpoint and each power-edge source (universe
      ≤ √max_p, exact counts, 64-bit).
- [ ] Sieve null for the same counts: expected routings from the covering
      conditions on the intermediate primes (the lab-notes machinery:
      ord₂-keyed kills, per-position density). Null computed, not fitted.
- [ ] Compare per class and in aggregate; overdispersion of routing counts is
      the object of interest — the chain-level analogue of the k-dispersion
      ledger deficit (covering-null CV² 0.0635 vs required 0.10–0.13).
- [ ] Record findings in lab-notes style; what deviates becomes the input to
      phase 05's decision about what pp-graph should persist.
